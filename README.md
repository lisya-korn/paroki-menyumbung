# Website Paroki Menyumbung

Website resmi Paroki Menyumbung, Desa Menyumbung, Kecamatan Hulu Sungai, Kabupaten Ketapang, Kalimantan Barat.

## Tentang

Website ini menampilkan informasi mengenai kegiatan iman, budaya, sosial, ekonomi, dan informasi penting lainnya dari Paroki Menyumbung.

## Tech Stack

- **Frontend**: Next.js 15 (App Router) + TypeScript
- **Backend**: Laravel (terpisah)
- **Styling**: Vanilla CSS

## Getting Started

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
